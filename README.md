# Engineering Intelligence Hub

A Retrieval-Augmented Generation (RAG) project designed to help users search and retrieve relevant information from software codebases and technical documentation.

## Overview

The Engineering Intelligence Hub aims to make it easier to understand software projects by retrieving relevant information from code and documentation and using it to support answers to technical questions.

## Key Features

- **Document Ingestion:** Load supported documents into the retrieval pipeline.
- **Codebase Understanding:** Designed to support searching software source code and technical information.
- **Semantic Search:** Retrieve relevant information based on the meaning of a query.
- **RAG-Based Question Answering:** Use retrieved context to help generate relevant answers.
